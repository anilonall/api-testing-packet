# Contributing

Thank you for improving API Testing Packet. Open an issue for substantial behavior changes and keep pull requests focused.

1. Fork and create a descriptive branch.
2. Never add real credentials or captured production responses.
3. Add tests for behavioral changes and an EF migration for schema changes.
4. Run the backend and frontend quality commands in the README.
5. Update documentation when public behavior or configuration changes.

By participating you agree to the Code of Conduct. Security reports must follow `SECURITY.md`, not a public issue.
