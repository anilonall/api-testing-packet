# Branding

The API Testing Packet mark combines a package wireframe with a terminal prompt: portable API definitions plus executable checks. The teal palette matches the workbench's status and action colors while remaining legible on the dark navigation surface.

The logo and mark in `frontend/public/branding` are original project artwork created for this repository. They do not derive from a third-party icon set and require no external attribution. They are distributed under the repository's MIT license.

- Use `logo-mark.svg` for compact UI placements and square avatars.
- Use `logo.svg` for repository and documentation headers.
- Keep clear space around the mark equal to at least one quarter of its width.
- Do not recolor individual packet faces or distort the artwork.
